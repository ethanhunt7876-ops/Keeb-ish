# Keeb-ish - Custom Mechanical Keyboard

## What I Built
A custom 65% mechanical keyboard with dual rotatory encoders, OLED display, and RGB underglow. Designed from scratch using Kicad for the PCB, Onshape for the case, and CircuitPython/KMK for firmware.

## Why
I wanted to learn PCB design, embedded programming, and mechanical design by building something I'd actually use daily. This project combines electronics, firmware, and industrial design into one portfolio piece.

## What I Learned
-How to design a keyboard matrix and route a PCB in Kicad
-How to write firmware for matrix scanning, encoders, and OLED
-How to design a 3D-printed case with proper tolerances
-How to document a complex project from start to finish
